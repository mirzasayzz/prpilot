PRPilot

Privacy Policy

Last updated · December 28, 2025

1. Introduction

PRPilot ("we", "our", "us") provides an automated code review service for GitHub. We are committed to protecting your privacy and the security of your code.

2. Data we collect

We collect the minimum data necessary to provide the service:

  • GitHub metadata — repository names, PR numbers, commit hashes, file names (to perform reviews).
  • Code content — we temporarily process the code in your pull requests to generate reviews. We do not store your code.
  • API keys — if you provide your own Gemini or Groq key, it is stored in an encrypted format.
  • Usage logs — basic success/failure metrics for debugging.

3. How we use data

  • To perform code analysis using large language models (Gemini, Groq, and fallback providers).
  • To post review comments on your GitHub pull requests.
  • To maintain your configuration settings (enabled reviewers, preferences).

4. Data storage & security

  • Encryption — API keys are encrypted at rest using industry-standard Fernet (AES) encryption.
  • No code retention — your code is sent to the LLM provider for analysis and not retained. We do not train models on your code.
  • Database — metadata is stored in Supabase (PostgreSQL) with Row Level Security enabled.

5. Third-party services

Reviews are powered by third-party LLM providers (Google Gemini, Groq, and fallbacks). Code snippets are transmitted to those providers solely to generate the review and are not stored by us.

6. Contact

For any privacy questions, please open an issue on our GitHub repository.
