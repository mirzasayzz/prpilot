4. Usage cap

Installations other than the owner account are capped at 25 reviews per day by default, counted over a 24 hour window by default. When the cap is reached, further reviews are skipped instead of consuming provider quota. Very large pull requests may be reviewed in part only, within limits documented in the README and shown on the dashboard.

6. Data and subprocessors

Pull request diffs and review context are sent to LLM providers in the failover chain (Gemini, Groq, Cerebras, OpenRouter, and LLMApi), review metadata is stored in Supabase, and the site is hosted on Vercel. See the Privacy Policy for the full list, retention, and uninstall deletion. GitHub App permissions are listed on the GitHub App install page.
