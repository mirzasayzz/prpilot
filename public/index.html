Honest limits

What PRPilot costs, and where it stops

PRPilot is free to install. It is not unlimited, and it is not a compliance product. Read the limits before you install.

Free app, bring your own key

PRPilot itself charges no fee to install. You supply your own LLM API key, for example Google Gemini or Groq, and you pay that provider under your own account for the usage your reviews create. If your key is missing, invalid, or out of quota, reviews can fail or be skipped.

25 reviews a day for non-owners

Installations other than the owner account are capped at 25 reviews per day by default. When the cap is reached, further reviews are skipped instead of consuming provider quota. The owner account is not subject to that cap, as documented in the README.

First-files and diff limits

Very large pull requests may be reviewed in part only. Any first-files or diff size limits are documented in the README and shown on the dashboard. This page does not invent a file or line number that is not in those sources.

AI reviews can be wrong

Reviews are generated by AI and may contain errors. Always verify suggestions before merging. PRPilot is a review aid, not a guarantee that code is secure, correct, or compliant.

Access and trust

Permissions, languages, and providers

What PRPilot can access, what it can review, and which services handle your data.

GitHub App permissions

Permissions are listed on the GitHub App install page. Check that page before you install, and install only on the repositories you want reviewed. The install page is the authoritative list if it differs from any other page.

Install link: github.com/apps/prpilot-mirzasayzz

Supported languages

The README names these languages: Python, JavaScript, TypeScript, Go, Java, and C++. The README also says "and more" without naming other languages, so this page does not list any language beyond those six names.

Providers that process review data

Pull request diffs and review context are sent to LLM providers in the failover chain and to the hosting and storage services below. See the Privacy page for the full list and what each service does.

  • Gemini
  • Groq
  • Cerebras
  • OpenRouter
  • LLMApi
  • Supabase (review storage)
  • Vercel (hosting)

Data retention and uninstall

Review metadata is retained until uninstall or on request. It is not kept for a fixed number of days stated on this page, because no fixed retention period was verified. On uninstall, PRPilot stops reviewing new pull requests. Ask for deletion of your stored review metadata at any time through the repository contact on the Privacy page.

FAQ

Questions, answered plainly

Is PRPilot free?

Yes, PRPilot is free to install and charges no fee itself. You still need your own LLM API key, and you pay that provider for usage. There is no credit card step in PRPilot itself, and there is no paid plan described on this page.

Do I need my own API key?

Yes. PRPilot uses a bring-your-own-key model. You provide a valid key, for example Google Gemini or Groq, and you are responsible for charges and quota on that provider account. An invalid or exhausted key can cause reviews to fail or be skipped.

What happens when I reach the daily cap?

For non-owner installations, the default cap is 25 reviews per day. When the cap is reached, further reviews are skipped until the next window instead of consuming provider quota.

What happens on uninstall?

PRPilot stops reviewing new pull requests after you uninstall it. Review metadata is retained until uninstall or on request, as stated in the retention section above. To ask for deletion of stored review metadata, contact the maintainer through the repository linked on the Privacy page.

What languages does PRPilot review?

The README names Python, JavaScript, TypeScript, Go, Java, and C++, and says "and more" without naming others. If your language is not named here, do not assume it is fully supported.

What data is sent to LLM providers?

Pull request diffs and the context needed to review them are sent to the LLM provider handling that review, through the failover chain: Gemini, Groq, Cerebras, OpenRouter, or LLMApi. Review results are stored in Supabase and the site is hosted on Vercel. Do not include secrets in a pull request and expect them to stay private: hardcoded secrets in code are exactly what the security agent is designed to flag, and review text may quote code from the diff.

What permissions does PRPilot need?

Permissions are listed on the GitHub App install page. Read that page before installing, and limit the installation to the repositories you want reviewed.
