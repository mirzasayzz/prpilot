## 4. Usage Cap

Installations other than the owner account are capped at 25 reviews per day by default, counted over a 24 hour window by default. When the cap is reached, further reviews are skipped instead of consuming provider quota. Very large pull requests may be reviewed in part only, within limits documented in the README and shown on the dashboard.

See PRIVACY.md for the full list, retention, and uninstall deletion. GitHub App permissions are listed on the GitHub App install page.
